# Security reporting

Report suspected vulnerabilities privately to **agentpay@mail.c4r.fun**, or use
GitHub private vulnerability reporting when available. Do not post keys, Provider
credentials, passwords, private requests/results or replayable signed payloads.

Include the affected version/commit, impact and sanitized reproduction steps using
disposable fixtures. Do not test attacks against real users or funded Orders.

This reference Provider is unaudited. Source publication and private test results
are not approval for production or real funds. Authentication, Order authorization,
execution replay, receipt recovery, private data and package integrity are in scope.
